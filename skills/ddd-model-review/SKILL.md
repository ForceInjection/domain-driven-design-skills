# DDD Model Review

## 使用时机

- 战术建模完成后，需要对整体模型做质量门禁检查。
- 已有建模工件需要全面评估（可作为独立入口使用）。
- 定期模型健康检查：团队希望量化模型质量并识别退化趋势。

## 输入要求

- **必需**：至少需要以下工件中的 3 项以上：
  - 上下文目录与词汇表（来自 `ddd-contexts`）
  - 上下文关系矩阵（来自 `ddd-context-map`）
  - 聚合目录与不变量表（来自 `ddd-aggregates`）
  - 领域事件目录与服务定义（来自 `ddd-domain-interactions`）
- **可选**：子域分类（来自 `ddd-subdomains`）、事件流（来自 `ddd-discover`）、scope 定义（来自 `ddd-scope`）。

## 流程

1. **术语一致性检查**：扫描所有工件中的术语使用，检测跨工件的命名冲突、定义漂移、同名不同义。
2. **边界一致性检查**：验证聚合边界是否与上下文边界一致——不变量不应跨越上下文。
3. **完整性检查**：核对事件流中的每个事件是否在事件目录中有正式定义；每个命令是否有对应聚合处理。
4. **耦合分析**：评估上下文间耦合度——依赖方向、共享数据量、同步调用数。
5. **评分**：对以下维度 0-10 评分：术语一致性、边界合理性、不变量表达率、事件完整性、耦合度。
6. **问题清单与回溯触发**：输出发现的问题、影响、证据、建议修复方案，并按触发条件生成回溯指令。

## 输出

| 工件         | 结构要求                                                                                         |
| :----------- | :----------------------------------------------------------------------------------------------- |
| 评分总览     | 表格：维度（术语一致性、边界合理性、不变量表达率、事件完整性、耦合度）、得分(0-10)、主要扣分原因 |
| 问题清单     | 表格：问题、影响、证据（引用具体工件）、建议修复、优先级                                         |
| 回溯触发清单 | 表格：触发条件、回溯目标 Skill、说明                                                             |
| 实施就绪判定 | 结论：Ready / Not Ready + 阻塞项列表                                                             |

## 校验清单

- [ ] 每个扣分项都提供可复核的证据（引用具体工件与条目）
- [ ] 回溯触发条件明确且可执行
- [ ] 评分可重复（相同输入得到相同分数）
- [ ] 实施就绪判定有明确的通过/不通过标准

## 回溯触发

本 Skill 是反馈闭环的核心触发器。根据评估结果触发以下回溯：

| 触发条件                   | 回溯至                    | 说明                             |
| :------------------------- | :------------------------ | :------------------------------- |
| 聚合边界与上下文边界矛盾   | `ddd-contexts`            | 上下文需重新划分以容纳一致性需求 |
| 术语冲突率 > 20%           | `ddd-contexts`            | 通用语言定义不充分               |
| 不变量表达率 < 60%         | `ddd-aggregates`          | 聚合可能为数据容器而非行为边界   |
| 集成模式与上下文映射不一致 | `ddd-context-map`         | 战术层发现了新的集成需求         |
| 事件完整性 < 70%           | `ddd-domain-interactions` | 事件目录缺失或未覆盖关键流程     |

**防止无限循环**：同一回溯路径最多执行 3 次。若第 3 次仍触发，标记为"需人工介入的架构决策"。

## 示例

```text
@ddd-model-review
请对以下建模工件做全局质量评估：
- 上下文目录：[粘贴]
- 聚合目录：[粘贴]
- 领域事件目录：[粘贴]
- 上下文关系矩阵：[粘贴]
请输出分维度评分、问题清单与回溯建议。
```
